# Grafana Synthetic Monitoring Lab

## Objective
Measure how reliably a web endpoint can be reached from two locations
and verify that Grafana sends an alert when a check repeatedly fails.

## Check configuration
Record each check's target, probe locations, frequency, timeout, and
success criteria.

## Probe locations and frequency
Explain the simulated user locations and the five-minute interval.
Record the monthly usage estimate shown in Grafana.

## Results and alert test
Record the test window, observed uptime, latency by probe, reachability,
and certificate expiry. Describe the controlled failure, the notification
received, and the recovery.

## Evidence
Embed the screenshots and link any Terraform files you used.
